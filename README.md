# StreamIt — By Ema

## Installazione
Aggiungi https://bonalapizza9.github.io/streamit/ in Kodi → Gestione file → Aggiungi sorgente.
Installa repository.streamit-1.0.7.zip, poi StreamIt da Installa da repository.

[Repository](https://bonalapizza9.github.io/streamit/repository.streamit-1.0.7.zip) · [StreamIt 1.10.0](https://bonalapizza9.github.io/streamit/plugin.video.streamit/plugin.video.streamit-1.10.0.zip)

## Lingua audio
A ogni apertura del menu principale scegli Italiano, Inglese, Spagnolo, Francese, Tedesco oppure Originale / predefinita.
La scelta vale per film e serie della sessione. Annullando, l’apertura viene interrotta.
La lingua viene preferita prima dell’avvio e selezionata quando la relativa traccia è disponibile.
Se manca la traccia scelta, resta l’audio disponibile. Originale / predefinita usa la traccia predefinita del video, che può essere doppiata.
Puoi cambiare lingua nel lettore durante la visione.
